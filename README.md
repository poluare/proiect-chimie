# proiect-chimie
Proiect chimie.Poluarea apei,aerlui si a solului.Clasa a VII-a A

Acest website de tip prezentare are scopul de a informa despre poluarea apei, aerului și a solului. De asemenea, există și o pagină cu un experiment despre poluarea petrolieră a apei. Pentru a o demonstra vizual, am folosit o sticlă, în care am pus apă, ulei și ulterior detergent. Uleiul, din cauza densității mai mici, se așează deasupra apei, fiind un strat gros care împiedică lumina și oxigenul să ajungă la viața acvatică. Adăugând detergent, care are o proprietate tensioactivă, prin fenomenul de emulsifiere, uleiul se împrăștie prin apă, fiind inevitabil animalelor acvatice. Acest proces duce la intoxicare.
Proiectul nostru are scopul de a transmite un mesaj: "Niciodată nu este prea târziu pentru a face o schimbare."
Pământul este în mâinile noastre. Noi avem misiunea de a-l îngriji cum avem grijă de noi.
